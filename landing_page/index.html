FAQ

Frequently Asked Questions

Core technical specifications, safety, and runtime requirements.

What is Klix Code? +

Klix Code brings Cursor and Claude Code workflows directly to Android. It pairs an autonomous multi-turn agent loop with an unrooted local Alpine Linux PRoot userland, the native Sora code editor, unified diff reviews, and 100% BYOK privacy.

Do I need root access on my Android phone? +

No root access is required. Klix Code uses PRoot to execute an unrooted Alpine Linux userland inside the app's sandboxed storage. You can run Node.js, Python, Git, and shell tools safely without touching the host Android OS.

Are my API keys sent to any Klix server? +

No. Klix Code operates without any intermediate relay server. Your API keys are encrypted at rest with Android Keystore, and model calls travel directly from your device to the model provider (Anthropic, OpenAI, or Google) over TLS 1.3.

Can I open project folders on my phone's storage? +

Yes. Klix Code integrates with Android's native Storage Access Framework (SAF). You select your project directory once, and persistent URI permission allows you to work across app restarts without re-prompting.

Will long agent tasks get paused when my screen turns off? +

No. Klix Code runs multi-turn agent execution inside an Android Foreground Service with a persistent status notification, preventing Android Doze from pausing execution while your phone is locked.
