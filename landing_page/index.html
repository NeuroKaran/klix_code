Questions & Answers

Frequently Asked Questions

What is KlixCode (Klix Code)? +

KlixCode (also known as Klix Code) is a mobile-first autonomous AI coding environment for Android. It lets you run an unrooted Alpine Linux userland with Node.js, Python, and Git via PRoot, orchestrate multi-step autonomous agent tasks (Claude, GPT, Gemini), review diffs, and build real software right on your Android phone with 100% BYOK privacy.

Do I need root access on my phone? +

No root access is required. Klix uses proot to run an unrooted Alpine Linux userland inside the app's sandboxed storage. You can run Node.js, Python, Git, and shell tools safely without touching the Android OS.

Are my API keys sent to any server? +

No. Klix does not operate an intermediate relay server. Your API keys are encrypted at rest with Android Keystore, and model calls travel directly from your device to the model provider (Anthropic, OpenAI, or Gemini) over TLS.

Can I open project folders on my phone's storage? +

Yes. Klix integrates with Android's Storage Access Framework (SAF). You select your project directory once, and persistent URI permission allows you to work across app restarts without re-prompting.

Will long agent tasks get paused when my screen turns off? +

No. Klix runs multi-turn agent execution inside an Android Foreground Service with a persistent status notification, preventing Android Doze from pausing execution.
