# Terminal Rain

Streams of glowing glyphs raining down in layered columns

- Type: React Bits Pro component
- Category: Backgrounds
- Docs: https://pro.reactbits.dev/docs/components/terminal-rain
- Registry item: @reactbits-starter/terminal-rain-tw

## Installation

```bash
npx shadcn@latest add @reactbits-starter/terminal-rain-tw
```

Requires a React Bits Pro license key and the @reactbits-starter registry configured in components.json. Setup guide: https://pro.reactbits.dev/docs/installation
